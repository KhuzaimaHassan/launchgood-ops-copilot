# Product Documentation

This layer defines what LaunchGood Ops Copilot is expected to do before implementation begins.

## Documents

1. [`PRD.md`](PRD.md) defines the product problem, users, goals, boundaries, workflow, and MVP definition of done.
2. [`requirements.md`](requirements.md) converts the product intent into testable requirements and acceptance criteria.
3. [`user-flows.md`](user-flows.md) defines the expected reviewer journey, lifecycle states, failure handling, and evaluation flow.
4. [`decision-log.md`](decision-log.md) records decisions that must remain consistent across architecture and implementation.

All three primary documents are versioned together as the approved product baseline `v0.2`.
